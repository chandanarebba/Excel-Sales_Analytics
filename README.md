
# Atliq Hardware – Sales & Financial Analytics Project (Microsoft Excel)

## Project Overview

Atliq Hardware is a company that sells computer hardware components such as PCs, keyboards, and mice. The company had sales data stored across multiple sources, making it difficult to analyze business performance and generate meaningful insights.

The objective of this project was to build interactive and easy-to-understand sales and financial reports in Microsoft Excel to improve data analysis, track performance, and support better business decision-making.

## Project Goals

* Develop Excel-based sales and financial reports to monitor business performance.
* Transform complex data into clear and actionable insights.
* Enable users to analyze sales trends, profitability, customers, and market performance efficiently.

---

# Sales Analytics Report

## Objective

* Create sales reports to analyze customer performance and market trends.
* Support data-driven decision-making by providing clear visibility into sales performance.

## Key Achievements

* Developed customer and market performance reports using Excel.
* Analyzed sales growth trends from 2019 to 2021.
* Compared actual sales performance against sales targets.
* Identified top-performing customers and high-growth markets.
* Improved visibility into sales performance through structured reporting.

---

# Financial Analytics Report

## Objective

* Create Profit & Loss (P&L) reports to evaluate financial performance.
* Analyze profitability across fiscal years, months, and markets.

## Key Achievements

* Built P&L reports based on fiscal year, month, and market analysis.
* Monitored sales, costs, and gross margin trends over time.
* Compared financial performance across different markets.
* Simplified financial reporting to make insights easier to understand and analyze.

---

# Technical Skills

* Applied the ETL (Extract, Transform, Load) process to clean, transform, and prepare data for analysis.
* Created dynamic date tables using Power Query.
* Developed fiscal months and quarters for financial reporting.
* Built data model relationships using Power Pivot.
* Integrated additional data sources into existing data models.
* Used DAX to create calculated columns and support analytical calculations.
